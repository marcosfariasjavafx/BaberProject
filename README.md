# The Best Barber Landing

Create a modern, clean, light-mode landing page for a barbershop named "The Best". The page must be fully responsive, visually stunning, and built with React, Tailwind CSS, Lucide icons, and Framer Motion for smooth animations.

1. Visual Identity & Theme (Light Mode):

Name: The Best

Slogan / Tagline: "Minha Fé nasce aqui"

Theme: Clean Light Mode. Predominantly white, off-white, and soft light gray backgrounds for a hygienic, premium, and sophisticated look.

Color Palette: Vibrant Purple/Violet as the primary brand color for buttons, highlights, accents, and icons. Dark charcoal/black for text to ensure high contrast and legibility.

2. Core Sections & Features:

Hero Section (with Video Background):

Full-screen height header with a subtle background video loop (barbershop environment) with a soft light overlay/mask so text remains easy to read.

Main headline featuring the brand name "The Best".

Slogan Animation: Animate the slogan "Minha Fé nasce aqui" using Framer Motion so that each letter rises/reveals individually letter-by-letter when scrolled into view or loaded.

Main CTA Button: "Agendar Horário" styled with a sleek purple gradient, linking directly to WhatsApp with pre-filled text: "Olá! Gostaria de agendar um horário na The Best."

About Us Section:

A clean, welcoming paragraph highlighting the premium experience and quality service.

Cut Portfolio / Photo Gallery:

A modern grid/masonry gallery showcasing haircut examples using high-quality Unsplash barbershop placeholders.

Interactive hover effect (soft zoom-in and purple shadow overlay).

Our Barbers (Team):

3 styled cards for the barbers, with avatar placeholders, names, specialties, and an individual "Agendar" button linking to WhatsApp:

Pietro - Especialista em Cortes Modernos e Fade (WhatsApp msg: "Olá! Gostaria de agendar com o Pietro na The Best.")

Julia - Especialista em Visagismo e Barba (WhatsApp msg: "Olá! Gostaria de agendar com a Julia na The Best.")

Ge - Especialista em Cortes Clássicos e Toalha Quente (WhatsApp msg: "Olá! Gostaria de agendar com o Ge na The Best.")

Services & Pricing (Interactive Cards/Grid):

Avoid plain tables. Use elegant card grids with purple icons, service titles, short descriptions, estimated duration, and prices (e.g., Corte, Barba, Combo, Sobrancelha).

Location & Contact:

Address, opening hours, contact details, and an embedded responsive Google Maps iframe.

Footer:

Social media links, quick navigation, and copyright text.

3. Animations & Scroll Effects:

Floating SVG/Vector element of a razor blade or scissors that subtly translates or rotates on scroll along the page side.

Smooth scroll navigation and stagger fade-in animations on all section cards using Framer Motion.
